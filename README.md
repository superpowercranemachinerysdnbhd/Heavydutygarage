# Heavyworks Garage

Workshop management system for a heavy machinery service and repair business.

- [`web/`](web/README.md): **the app (Phase 1)** — Next.js + PostgreSQL. Setup instructions inside.
- [`docs/DESIGN.md`](docs/DESIGN.md): full system design (roles, job categories and lifecycle, modules, data model, ideas, tech stack, rollout plan)
- [`docs/RENTAL.md`](docs/RENTAL.md): design of the **Super Power Crane Machinery Sdn Bhd rental system**: enquiries and follow-ups, customers, quotations and orders, fleet planner and bookings, calendar, staff rosters and leave, dry/wet hire, transport, timesheets, billing with SST and MyInvois e-invoicing
- [`prototype/rental.html`](prototype/rental.html): clickable prototype of the Super Power Crane Machinery system with example data (opens on the dashboard)
- [`prototype/index.html`](prototype/index.html): clickable prototype with example data covering all phases. Open it in a browser.
